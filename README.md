# Jitendra Sethia - Portfolio Website

A modern, light-themed portfolio website showcasing my journey as a Software Engineer, Full-Stack Developer, and AI Innovator.

## Features

- **Loading Screen**: Custom animated loading screen with portfolio branding
- **Solar System Skills Animation**: Unique interactive visualization of technical skills
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Scroll-triggered animations and smooth transitions
- **Project Showcase**: Detailed project cards with technologies and features
- **Timeline Experience**: Visual timeline of achievements and experience
- **Easy Navigation**: Fixed navbar with smooth scrolling

## Technologies Used

- HTML5
- CSS3 (Custom animations, Flexbox, Grid)
- Vanilla JavaScript
- Font Awesome Icons

## Sections

1. **Home/Hero**: Introduction with social links
2. **About**: Personal background and highlights
3. **Skills**: Interactive solar system visualization + categorized skills
4. **Projects**: Featured projects with detailed descriptions
5. **Experience**: Timeline of achievements and roles
6. **Contact**: Multiple ways to connect

## Setup

Simply open `index.html` in your browser. No build process required!

## Customization

To add your project links, update the `projectLinks` object in `script.js`:

```javascript
const projectLinks = {
    'GramLink AI': 'https://your-project-url.com',
    'FarmLink AI': 'https://your-project-url.com',
    // ... add more projects
};
```
