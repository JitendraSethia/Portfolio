# Assets Folder

## How to Add Your Resume/CV

1. **Save your resume** as a PDF file
2. **Rename it** to: `Jitendra_Sethia_Resume.pdf`
3. **Copy it** to this `assets` folder
4. The download button on your portfolio will automatically work!

**Recommended:**
- File format: PDF (most professional)
- File name: `Jitendra_Sethia_Resume.pdf`
- File size: Keep under 2MB for fast downloads

Once you add your resume here, the "Download Resume" button will work automatically.
